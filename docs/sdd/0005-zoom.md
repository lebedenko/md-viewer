# 0005 — Reader zoom

Status: Complete
Authorization: Owner request to proceed with the next roadmap item; scope narrowed by the owner to keyboard zoom
(Ctrl+= / Ctrl++ / Ctrl+- / Ctrl+0) implemented with style font overrides.

## Problem and outcome

Text size is fixed. After this change the reader zooms in discrete steps from the keyboard, the choice persists
between runs, and rendering stays crisp because text is re-laid out rather than scaled as a bitmap.

## Scope and non-goals

- Steps: 0.5, 0.67, 0.8, 0.9, 1.0, 1.1, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0. Zoom in/out moves to the neighbouring step of
  the nearest current value, clamped at the ends; Ctrl+0 resets to 1.0.
- The column width limit (800 logical px) is unchanged; zoom changes characters per line.
- Non-goals (remain in the roadmap item): width presets, light/dark override, small-type preferences, toolbar zoom
  controls and a zoom indicator, mouse-wheel zoom.

## Design and decisions

- QMarkdown 1.10 has no zoom API. `ReaderPane` keeps a second preset-only `MarkdownStyle` (`baseline`) and assigns the
  public `bodyFont`, `codeBlockFont`, `inlineCodeFont` and `h1Font`…`h6Font` style properties as the baseline fonts with
  `pointSize * zoom` (point sizes only). No private API. Header/footer chrome and the "Copy code" label are not zoomed.
- Zoom is stored with `QtCore.Settings` (`reader/zoom`); `main.cpp` sets the organization name. Tests enable
  `QStandardPaths` test mode so they never touch real user settings.
- Tests link `Qt6::Test` for key events.
